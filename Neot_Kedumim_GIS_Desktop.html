      ייבוא GeoJSON

      תומך: .geojson, .json

      ייבוא KML / KMZ

      תומך: .kml (Google Earth)

      ייבוא CSV (קואורדינטות)

      עמודות נדרשות: lat, lng (או lon), name

      ייבוא שכבת WMS
      ייבוא GeoJSON מ-URL
      ייבוא Shapefile (SHP)

      יש לדחוס קבצי .shp / .dbf / .prj לתוך קובץ ZIP אחד

      ייבוא DWG / DXF (AutoCAD)

      תומך DXF בלבד. קבצי DWG אינם נתמכים — יש לשמור מ-AutoCAD: File → Save As → AutoCAD 2013 DXF (או 2010 DXF).

      ייבוא LYR / LYRX (ArcGIS)

      תומך LYRX (ArcGIS Pro – JSON). קבצי .lyr בינאריים אינם נתמכים ישירות.

      ייבוא ECW / GeoTIFF (רסטר)
      כיצד לטעון קובץ ECW:
      קבצי ECW אינם נתמכים ישירות בדפדפן — יש להמירם ל-GeoTIFF ב-QGIS:
      QGIS → Raster → Convert → Translate (GeoTIFF)
      לביצועים טובים בחרי Cloud Optimized GeoTIFF (COG) ביצוא.
      90%

      תומך: .tif / .tiff | קבצי ECW יש להמיר תחילה ל-GeoTIFF
